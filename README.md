# Shipment Delivery Analysis and Delay Prediction System
## Project Overview
This project analyzes shipment and logistics data to identify factors affecting delivery performance and shipment delays.

## Tools Used
- SQL
- Python
- Pandas
- Matplotlib
- Power BI
- Streamlit
- MySQL

## Project Tasks
- Data cleaning and preprocessing
- SQL querying and analysis
- Dashboard creation
- Data visualization
- Shipment delay analysis

## Key Insights
- Analyzed delivery patterns
- Identified factors affecting on-time delivery
- Studied warehouse performance
- Compared shipment modes and product importance
